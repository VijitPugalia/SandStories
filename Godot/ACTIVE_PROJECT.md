# Active Godot Project

This is the active SandStories Godot visualization project.

Use this directory for all future Godot work:

```text
SandStories/Godot/
```

The older standalone sibling directory `SandStoriesGodot` is deprecated and should not receive new changes.

Large generated/captured data remains local and ignored by git:

- `assets/sessions/`
- `assets/processed_sessions/`
- `assets/experiments/`
- `.godot/`
- `.venv/`
- `build/`
- `export_templates/`
