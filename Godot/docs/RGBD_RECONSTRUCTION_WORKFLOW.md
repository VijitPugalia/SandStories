# RGB-D Reconstruction Workflow

This document describes the retained v20d geometry/hand baseline and the
bounded v21b shadow-removal review candidate. The important design rule is that
display RGB, sand depth, and the virtual hand are independent products. A
generated RGB frame is never recycled as geometric evidence.

## Layer provenance

| Layer | Source | Boundary |
|---|---|---|
| Displayed sand RGB | Grounded-SAM-2 masks and ProPainter; v21b optionally replaces frames 40-124 with a Casper result | Display only |
| Sand depth | Quality-filtered Kinect evidence, Any2Full Large, and VDA-delta temporal stabilization | Frozen before later RGB and hand work |
| Virtual hand | Temporally stabilized MANO meshes anchored to registered RGB-D and rendered with the cerulean material | Separate 3D overlay |

The reviewed sequence contains 714 frames over 23.7677 seconds. v20d is the
retained visual baseline. v21b is marked as a review candidate because its
85-frame shadow-reduced interval contains generative output.

## Display RGB

The base displayed-RGB sequence starts from the 714 raw Kinect RGB frames. It
does not start from the historical v44 restoration or the RGB made for
Any2Full conditioning.

Hand and arm masks are generated by Grounded-SAM-2:

- Grounded-SAM-2 commit:
  `b7a9c29f196edff0eb54dbe14588d7ae5e3dde28`
- detector: `IDEA-Research/grounding-dino-tiny`
- segmenter: SAM 2.1 Hiera Large, `sam2.1_hiera_large.pt`
- prompt: `hand. arm.`
- detection interval: every 10 frames
- box/text thresholds: `0.35` / `0.20`
- propagation: one continuous object ID forward plus reverse propagation
- selected masks: 665 of 714 frames
- manual masks, spatial rules, and mask postprocessing: none

The masks are passed to official ProPainter commit
`e870e79321c31b733e2031af5aa2fb1fe3ac7eec` with:

```text
--save_frames --fp16 --mask_dilation 4
```

All other ProPainter settings use the official defaults. The result is 714
lossless 640 x 480 PNG frames. It removes the captured hand/forearm covered by
the model masks but deliberately makes no shadow-removal claim.

### Optional v21b shadow-reduced interval

The v21b probe changes only displayed RGB frames 40-124. It uses the full
Casper CogVideoX-5B clean-background model at 480 x 640 and 10 fps, with 50
DDIM steps, seed 43, and the same automatic actor masks. Three-way Ulysses
sequence parallelism runs the 5B model across three RTX 2080 Ti GPUs.

Casper supplies a counterfactual low-frequency appearance. Captured high
frequency detail is restored with a one-level Laplacian fusion:

```text
fused = source + blur(Casper, radius=1) - blur(source, radius=1)
```

The correction is restricted to the existing registered `surface_mask.png`.
Pixels outside the surface remain byte-identical. The retained probe preserves
about 97.4% of source sand high-frequency energy.

The final v21b display sequence is:

```text
frames 1-39:    Grounded-SAM-2 + ProPainter RGB
frames 40-124:  Casper low-frequency result + captured source detail
frames 125-714: Grounded-SAM-2 + ProPainter RGB
```

`materialize_rgb_only_review_session.py` creates this branch without
overwriting its source and records that depth, MANO, RGB-D fusion, and Any2Full
were not recomputed.

## Sand depth

The depth branch begins with libfreenect/Kinect v1 depth PGM frames. It keeps
only reliable sparse evidence:

- both surface and Kinect-valid masks are required;
- object-region depth is excluded after an 8 px dilation;
- encoded height is restricted to 40-230;
- a 9 x 9 median consistency check permits at most 8 grayscale levels;
- Sobel gradient is limited to 48;
- anchors are sampled at fixed grid4 locations.

The mean retained surface density is about 4.37%. The accepted capture
calibration spans 0.81286-0.92167 metres.

A separate object-masked RGB sequence conditions the completion model. Within
each `t-16..t+16` window it uses a temporal median for visible pixels, local
spatial fill for persistently masked pixels, and the window-local sand colour
outside the surface. This conditioning sequence is never displayed.

Any2Full Large produces the dense spatial reconstruction:

- repository commit:
  `780edf6be2bf9260f1cce8e4ddbcb52d7bcdae9e`
- encoder/variant: `vitl / vitl_object_masked_rgb`
- checkpoint: `Any2Full_vitl.pth.tar`
- inputs: grid4 Kinect anchors plus the window-16 conditioning RGB
- output: 714 metric-depth frames

Any2Full remains the spatial and metric source. Predictions are clamped to the
calibrated Kinect range when encoded for Godot, and a floating-point per-frame
baseline correction preserves the held-out Kinect median after PNG
quantization.

Two visible whole-surface jumps came from Kinect quantization transitions that
the completion model correctly followed. Video Depth Anything Small is
therefore used only as a temporal-delta guide:

- checkpoint: `video_depth_anything_vits.pth`
- method: bidirectional VDA-delta-guided adaptive smoothing
- strength: `0.92`
- encoded-difference threshold: `18`

VDA neither replaces Any2Full geometry nor defines absolute scale. The
stabilized depth keeps the Any2Full surface, rejects broad quantization steps,
and reduces the audited coherent-jump count from two to zero. Agreement with
held-out, quality-filtered Kinect evidence is approximately 1.319 mm mean MAE,
2.040 mm mean RMSE, and 3.465 mm mean P95 error. These values are sensor
agreement, not hidden-surface ground truth.

All later hand, material, experiment, and RGB-only branches reuse the same 714
depth frames. Godot samples them in `sand_depth.gdshader` with the session
height scale.

## Virtual hand

The retained v19i hand geometry uses an official MANO model fitted to
independent hand observations. The fit shares shape/camera scale across time,
uses temporal losses, rejects off-tray detections with the registered surface
ROI, and preserves genuine tracking gaps.

The closed MANO mesh is moved rigidly to a robust, fixed reference-surface
anchor. Per-vertex sand-height offsets are not applied because they deform the
hand. v20d changes only the hand material to an opaque, double-sided cerulean
shader; RGB, depth, MANO vertices, and mesh timing remain identical to v19i.

## Dependency direction

```text
Kinect depth evidence + safe conditioning RGB
  -> Any2Full Large
  -> VDA-delta temporal stabilization
  -> frozen sand depth

raw Kinect RGB
  -> Grounded-SAM-2
  -> ProPainter
  -> optional Casper display-only interval
  -> displayed sand RGB

frozen sand depth + independent hand observations
  -> stabilized MANO placement
  -> virtual hand rendered separately
```

## Reusable entry points

- `register_kinect_depth_rgb.py`: register captured Kinect depth to RGB.
- `analyze_depth_stability.py`: audit sensor agreement and coherent jumps.
- `stabilize_any2full_with_vda.py`: apply the VDA-delta temporal guide.
- `fit_mano_hand_only_sequence.py`: temporally fit the MANO sequence.
- `stabilize_mano_rgbd_surface_anchors.py`: apply the retained surface-anchor
  policy.
- `materialize_mano_rgbd_full_session.py`: create the RGB-D/MANO session.
- `run_casper_cog5b_3gpu_safe_amadeus.sh`: launch the three-GPU Casper probe.
- `fuse_casper_lowfreq_with_source.py`: restore captured image detail.
- `materialize_rgb_only_review_session.py`: create an explicitly RGB-only
  review branch.

Model weights, licensed MANO files, raw captures, and generated frame
sequences are intentionally not stored in Git.
